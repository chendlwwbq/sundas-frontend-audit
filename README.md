# SUNDAS Frontend Design Audit

**审计工具无法解压 ZIP？请从 [明文源码入口](START_HERE.md) 直接读取完整 TXT 或分段源码，无需解压。**

公开的前端设计与 UX 审计快照，包含实际页面、React 组件、样式、动画、静态素材及维持交互所需的前端状态。

这是一份独立导出，源代码快照为 `f73b4d7400ae53852b0b4032999ba5301e20c78d`。原项目和部署环境不受此仓库影响。

## 本地运行

需要 Node.js 22.12+（建议 Node.js 24）。

```sh
npm run setup
npm run dev
```

打开 http://127.0.0.1:3021 。默认使用虚拟审计账户，无需输入真实账号和密码。

```sh
npm run build
npm run preview
```

也可在 `web` 目录使用 Bun 安装依赖，依赖清单与锁文件保存在 `web` 下。

## 包含内容

- 首页、顶部导航、品牌和灵感大厅。
- 图片、视频、对话的统一创作入口，参数选择、参考素材和记录面板。
- 无限画布、节点、侧栏、生成面板、分镜弹窗及导演台三维交互。
- 提示词库、素材库、账户页和管理后台的前端界面。
- Tailwind/CSS 主题、组件状态、响应式布局、Motion 动画、Three.js 场景。
- 前端类型、状态和接口适配层，供组件解析和交互演示使用。

## 演示边界

所有账号、模型、积分及提示词数据均为本地示例。积分数字不代表真实报价。

`web/src/audit/demo.ts` 提供演示数据；`web/src/audit/install.ts` 接管 Fetch/Axios；前端通用请求入口已替换为本地数据调用。没有后端代理，不需要数据库、Redis、OSS 或任何密钥。页面禁用统计上报，并限制外部资源连接。

模型生成、视频渲染、支付、云端上传、后台数据修改等依赖服务的操作不会执行，会显示演示提示。未配置的列表可能为空；本地模型不具备真实生成或看图能力。画布本地编辑、界面菜单和弹窗仍沿用实际前端代码。模拟云端画布仅驻留内存，刷新后不保证恢复；此仓库不用于业务数据保存。

未包含服务端源码、数据库迁移、部署脚本、环境文件、真实用户数据、真实渠道参数或原仓库 Git 历史。原前端接口类型和展示状态仍保留，以保证页面能编译和阅读；它们不是可用的服务端 API。
